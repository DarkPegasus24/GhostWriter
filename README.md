# 👻 GhostWriter

GhostWriter is a sleek, Python-based desktop application that automatically types out your clipboard text like a real human. Built with a modern UI, it lets you paste large blocks of text, set a delay to switch to your target window, and watch as it flawlessly types everything out for you. 

Perfect for code demonstrations, bypassing paste-restrictions, or automating repetitive keystrokes!

### ✨ Key Features
- **Adjustable Typing Speed:** Control exactly how many characters are typed per second.
- **Smart IDE Indent Fix:** Automatically strips leading spaces before typing to prevent the "staircase effect" (exponential indentation) when typing into modern code editors like VS Code or IntelliJ.
- **Global Hotkeys:** Start typing (`Ctrl+Shift+T`) or instantly kill the process (`Esc`) from anywhere on your computer, even when the app is in the background.
- **Modern UI:** Features a beautiful dark-mode interface with a live character counter, progress bar, and visual countdown overlay.
